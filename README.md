# Quizzy

Quizzy is an interactive quiz application built with React that provides an engaging and responsive user experience. The application features animated transitions, real-time feedback, and detailed explanations for quiz questions.

![Quizzy App](https://via.placeholder.com/800x400?text=Quizzy+App)

## Features

- **Interactive Quiz Interface**: Engaging UI with smooth animations powered by Framer Motion
- **Real-time Feedback**: Immediate feedback on answer selection
- **Detailed Explanations**: Access to explanations for each question
- **Progress Tracking**: Visual progress bar and score counter
- **Responsive Design**: Works seamlessly across desktop and mobile devices
- **Results Summary**: Comprehensive summary with performance metrics at the end of the quiz

## Tech Stack

- **React**: UI library for building the interface
- **Framer Motion**: Animation library for smooth transitions
- **Lucide React**: Icon library for UI elements
- **Tailwind CSS**: Utility-first CSS framework for styling
